# Event Planner - Product Definition

## 1. Product Overview

Event Planner is a SaaS application that helps users plan,
organize and manage events from a single workspace.

The application initially targets weddings and private events,
with support for additional event types in the future.

## 2. Problem Statement

Event planning is currently fragmented across:

- WhatsApp
- Excel
- Google Sheets
- Notes
- Instagram/Pinterest
- Email
- Paper documents
- Phone contacts

Users need a single place to organize their event.

## 3. Product Vision

Create a simple, user-friendly event planning platform that
allows users to manage every important aspect of their event
from one place.

## 4. Initial Target Users

- Couples planning weddings
- People organizing birthdays
- Engagement organizers
- Baby shower organizers
- Anniversary organizers
- Small private event organizers

## 5. Initial Market

India.

The product may expand internationally later.

## 6. Core Value Proposition

Plan your entire event in one place.

## 7. Initial Event Types

- Wedding
- Engagement
- Birthday
- Anniversary
- Baby Shower
- Other

## 8. Business Model

Users receive a 3-day free trial.

After the trial expires, an active subscription
is required to continue using the application.
